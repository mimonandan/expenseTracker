Example: the ₹22,000 loan debit lands on the 3rd. It is already reserved, so it reduces “still due” commitments, not the daily guide a second time. If ₹1,200 goes to flexible purchases on day 1, the next guide becomes (₹55,000 − ₹1,200) ÷ 30 ≈ ₹1,793.
